# Egg Timer 🥚⏱️

A cute, scalable Flutter egg timer app (mobile + web), ready for CI and GitHub Pages deploy.

## Features
- Presets: Soft / Medium / Hard
- Custom minutes/seconds
- Start, pause, resume, reset
- Figma-friendly asset pipeline (SVG/PNG)

## Getting started
```bash
flutter pub get
flutter run
```

## Web
```bash
flutter run -d chrome
```
## Deployment

https://pallavikailas.github.io/egg-timer/
